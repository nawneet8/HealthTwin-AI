## 📌 Executive Summary & Problem Statement

### 🎯 The Healthcare Problem
Over **537 million adults** worldwide live with Type-2 Diabetes. Managing dysglycemia requires continuous monitoring, as acute hyper- and hypoglycemic events can lead to severe long-term microvascular and macrovascular complications. Traditional Electronic Health Records (EHR) capture static clinical snapshots (HbA1c, fasting glucose), missing real-time physiological dynamics. Conversely, dynamic wearable sensors (Continuous Glucose Monitors, Smartwatches) generate massive telemetry streams without holistic clinical context.

### 💡 The HealthTwin AI Solution
**HealthTwin AI** bridges clinical demographics with dynamic wearable IoT telemetry to build a continuous **Virtual Patient Digital Twin**. By assimilating historical EHR data and dynamic time-series signals (Heart Rate, HRV, Sleep, Steps, Stress, Glucose), HealthTwin AI continuously updates the virtual patient's state and predicts **glucose spikes approximately 2 hours in advance**.

## ✨ Key Features

1. **🔄 Continuous Digital Twin Engine:** Maintains real-time virtual patient representation, updating state dynamically as incoming wearable packets arrive.
2. **🔮 2-Hour Forward Predictive AI:** XGBoost machine learning classifier trained on multi-scale rolling temporal features to forecast glucose spike probability (`future_glucose_2h >= 175 mg/dL` or `delta >= 35 mg/dL`).
3. **📈 Time-Series Glucose Forecasting:** Ridge regression model projecting continuous glucose concentration 2 hours into the future with 95% confidence bounds.
4. **⚠ Unsupervised Anomaly Detection:** Isolation Forest algorithm detecting multivariate biometric outliers across HR, HRV, sleep deprivation, and stress spikes.
5. **🧠 SHAP Explainability (XAI):** Quantifies exact feature attributions and generates natural language explanations for clinical transparency.
6. **🧪 Counterfactual What-If Simulator:** Interactive slider interface allowing clinicians to test hypothetical lifestyle interventions (increasing sleep, steps, stress reduction) and observe predicted risk reduction.
7. **💾 Persistence & Database Layer:** Integrated SQLite database (`healthtwin.db`) structured for straightforward migration to PostgreSQL.

## ⚡ Installation & Quick Start

### 1. Clone & Setup Workspace
```bash
git clone https://github.com/your-org/HealthTwin-AI.git
cd HealthTwin-AI
```

### 2. Create Virtual Environment & Install Dependencies
```bash
python -m venv venv
# Activate on Windows:
venv\Scripts\activate
# Activate on Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Launch Streamlit Dashboard
```bash
streamlit run app.py
```
*The app will automatically generate realistic synthetic datasets and train machine learning models if artifacts do not exist.*
